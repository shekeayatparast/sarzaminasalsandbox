# سرزمین عسل — Sandbox Workspace (sarzaminasalsandbox)

این ریپو اسنپ‌شات کامل ورک‌اسپیس سندباکس پروژه «سرزمین عسل» است.

- **main**: آخرین وضعیت پروژه (سایت + پنل‌ها + ربات تلگرام + بسته دیپلوی)
- **deploy/**: بستهٔ نصب روی سرور شخصی (setup.sh سازگار با 3X-UI)
- برای دیپلوی روی سرور: `deploy/setup.sh` را اجرا کنید — راهنمای کامل در `deploy/README.md`

آخرین تغییرات: سیستم وبلاگ + حذف کامل پورسانت + حذف دکمه‌های پنل از هدر + طراحی مدرن + ستاپ سازگار با 3X-UI
